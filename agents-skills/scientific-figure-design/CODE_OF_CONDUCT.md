# Code of conduct

We want this project to be a constructive environment for researchers,
designers, engineers, and students.

Be respectful, specific, and evidence-driven. Critique the artifact or method,
not the person. Welcome questions across levels of design and engineering
experience. Do not harass, demean, threaten, or discriminate against others.
Do not publish another person's private information.

Maintainers may remove content or participation that violates these
expectations. Report conduct concerns privately through the repository owner's
GitHub profile. Good-faith reports will be handled discreetly and without
retaliation.
